## 🌟 Highlights & Features

- **⚡ Fast & Modern Architecture**: Built on Vite + React 18 + TypeScript with strict typing.
- **🎨 Glassmorphic Dark UI**: Custom slate/navy dark design system with dynamic glow orbs, frosted glass cards, and curated typography.
- **📱 Responsive & Interactive**: Smooth Framer Motion reveal animations, interactive skill filtering, modal deep-dives, and canvas-confetti celebration triggers.
- **🗃️ Redux Toolkit State Management**: Centralized store for skill category filters, modal views, contact form states, and notifications.
- **📄 Resume Integration**: Quick preview and one-click download of latest resume.
- **📬 Interactive Contact Module**: Validated form with real-time feedback, direct email launch, and social links.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 1. Clone the repository

```bash
git clone https://github.com/Vrushali-Pawar18/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

The app will run locally at `http://localhost:3000`.

### 4. Build for production

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
